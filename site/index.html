Back up your Claude Code work to your own Google Drive.

Phylax encrypts your project folders, Claude sessions and notes on your machine, uploads the ciphertext on a schedule, and keeps versions so you can go back to an earlier day. Your files stay where they are.

v1.0.0 · macOS tested · Windows not yet tested · FSL-1.1-ALv2

What it does

  • Files stay localPhylax copies to Drive and never syncs anything back over your files.
  • Encrypted firstYour machine holds a public key. It can write backups and cannot read them. The private key stays with you.
  • VersionedEvery change makes a snapshot. Daily, weekly and monthly snapshots are kept (14, 8 and 12 by default), so a deleted or overwritten file can be recovered.
  • Runs by itselfA background job runs every 30 minutes. The state shows in your Claude Code status line, and a failed backup raises a desktop notification.

Install

Each command downloads a release, checks its SHA-256, installs it and starts phylax setup.

macOS
$ curl -fsSL https://github.com/agentnetes/phylax/releases/latest/download/bootstrap.sh | bash
Windows (PowerShell)
PS> irm https://github.com/agentnetes/phylax/releases/latest/download/bootstrap.ps1 | iex

Homebrew and Scoop work too. Homebrew now asks you to trust a third-party tap first.

Homebrew
$ brew tap agentnetes/phylax https://github.com/agentnetes/phylax && brew trust agentnetes/phylax && brew install phylax
Scoop
PS> scoop bucket add phylax https://github.com/agentnetes/phylax; scoop install phylax

Setup asks for a project name and folder, opens your browser to connect Google Drive, creates your encryption key and schedules the backup. The Drive permission is limited to files Phylax creates itself.

Do this once

Setup creates your private key on this machine. Copy it into your password manager and delete the local file, because without it the backups cannot be restored. If you manage a team, add a second recovery key that IT holds with phylax add-recipient age1….

How it works

The scheduler starts a sync every 30 minutes. Phylax scans the folder, skips files that look like secrets in the readable manifest, encrypts what changed and hands the ciphertext to rclone. Local state under ~/.config/phylax (Windows %APPDATA%\phylax) remembers what was uploaded, which feeds the status line and the failure alerts.

This is what your Drive holds for a project called board:

board-context/
  CLAUDE.md            readable
  manifest.json        readable
  sessions-index.json  readable
  encrypted/
    board--claude-backup-<ts>.tar.gz.age
full mode
board-context/
  files/
    objects/<sha>.age          one per content
    snapshots/<ts>.json.age    one per change
  encrypted/
    board--claude-backup-<ts>.tar.gz.age

Backup modes

Each project folder picks a mode when you add it.

$ phylax init --name board --dir ~/Documents/Board --mode full
ModeWhat reaches DriveUse it for
contextA readable CLAUDE.md, a file manifest and a session index, plus your Claude sessions encrypted.Keeping Claude context safe when file names are not sensitive. Files that look like secrets are never listed.
fullEvery file encrypted under opaque names, with an encrypted index and snapshots. Names and contents are unreadable.Folders of real documents such as board papers or contracts.
bothEverything in full, plus encrypted Claude sessions.Folders where documents and Claude work live together.

Full mode skips files over 200 MB, temporary files and folders such as node_modules. A first upload over 2 GB needs one approval with --yes. Preview any run with --dry-run.

Commands

phylax menu
Interactive menu for everything below.
phylax sync [--dry-run]
Back up now. Add -p NAME for one project.
phylax status
Dashboard for every project. phylax watch keeps it live.
phylax doctor
Checks tools, Drive login, key, schedule and disk space, and says what to fix.
phylax projects
Lists configured projects. Bulk-add folders from the menu.
phylax prune [--dry-run]
Applies retention now. It also runs daily.
phylax restore-files
Lists restore points and restores files. See below.
phylax git-init
Optional private GitHub repo for a project folder, on your own account.
phylax update
Installs the latest release.

Restore

  1. On the new machine, install Phylax and run phylax setup with the same Google account.
  2. Get your private key out of your password manager and save it as a file, for example key.txt.
  3. List the restore points for a project.
  4. Restore everything, or only what matches, into a folder you choose.
$ phylax restore-files -p board --identity key.txt --snapshots
$ phylax restore-files -p board --identity key.txt --at 2026-11-10 --match budget --to ~/Restored

Restores never write over the original folder unless you pass --force. Claude sessions come back with phylax restore -p board --identity key.txt.

Security

  • Encryption is age, to public recipients. The backing-up machine cannot decrypt its own backups.
  • Drive access uses rclone with the drive.file scope, so Phylax only sees files it created.
  • The Google login lives in rclone's own config. The installer hides its output, because it contains tokens, and never prints your private key.
  • In context mode the manifest is readable, so file paths and sizes are visible on Drive. Use full or both mode if names matter.
  • Identical files show up as identical object names. Their content stays encrypted.
  • Deleted objects go to Drive's trash, which empties after 30 days.
  • If you lose the private key, nobody can recover the backups. That is by design.

Status

macOS is tested end to end. The Windows scripts are written and have not run on a Windows machine yet. If you try them, a short report helps a lot.

rclone's shared Google client ID is being retired in 2026. If syncs start failing with authorisation errors, create your own client ID and run rclone config update. The README has the steps.
